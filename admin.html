Bestand pflegen

GitHub-Token benötigt. So erstellst du es:

  1. Auf github.com einloggen → oben rechts Profilbild → Settings
  2. Ganz unten links Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Name z. B. „Bestand Admin“, Ablaufdatum wählen
  4. Repository access: „Only select repositories“ → nur automat-bestand
  5. Permissions → Repository permissions → Contents: Read and write
  6. Token erzeugen, kopieren und hier einfügen.

Das Token wird nur in diesem Browser (localStorage) gespeichert.
